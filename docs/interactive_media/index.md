# Interactive Media and User Experience

## Overview

### **Introduction to Interactive Media**

**Learning Intentions - Students will:**

- Investigate how interactive media and the user experience (UX) is used to communicate information to an audience
- Research the evolution of interactive media
- Understand the prevalence of blogs, online video and digital radio

**Curriculum Points Covered:**

- "Investigate how interactive media and the user experience (UX) is used to communicate information to an audience"
- "Research the evolution of interactive media" - "prevalence of blogs, online video and digital radio"
- "Describe the contribution of interactive media systems to a range of enterprises"

**Teaching Focus:**

- What is interactive media? (blogs, video, streaming, social media)
- Evolution from static to interactive content
- How businesses use streaming services, gaming, specialist apps
- **PRACTICAL:** Explore various platforms and critique UX

---

### **UX/UI Fundamentals**

**Learning Intentions - Students will:**

- Explain how the user interface (UI) impacts on the user experience (UX)
- Apply design tools and techniques to develop an engaging UI
- Apply design thinking to develop interactive media systems

**Curriculum Points Covered:**

- "Explain how the user interface (UI) impacts on the user experience (UX)"
- "Apply design tools and techniques to develop an engaging UI"
- "Apply design thinking to develop a front-end, web-based interactive media system incorporating UX and UI principles"
- "Explain how interactive media systems can support creative processes"

**Teaching Focus:**

- Design thinking process (empathise, define, ideate, prototype, test)
- User interface basics (navigation, consistency, feedback, affordance)
- User experience principles (usability, accessibility, desirability)
- Introduction to accessibility and opportunities for people with disability
- **PRACTICAL:** Paper prototyping exercise

---

### **Creating Interactive Content**

**Learning Intentions - Students will:**

- Select and use appropriate file formats for a defined purpose
- Use hardware and software to digitise assets for use in interactive media systems
- Understand lossy and lossless data compression
- Use software to develop elements of interactive media in a project

**Curriculum Points Covered:**

- "Select and use appropriate file formats for a defined purpose"
- "Use hardware and software to digitise assets for use in interactive media systems, including lossy and lossless data compression"
- "Use software to develop elements of interactive media in a project"
- "Capture, store and integrate data"

**Teaching Focus:**

- File formats and when to use them (JPEG vs PNG, MP4 vs MOV, etc.)
- Lossy vs lossless compression (practical implications for quality vs size)
- Basic HTML/CSS or no-code tool (choose one approach)
- **NEW:** How generative AI tools assist creation (demo ChatGPT, Canva AI)
- **PRACTICAL:** Build a simple interactive webpage/prototype

---

### **Social & Ethical Considerations**

**Learning Intentions - Students will:**

- Investigate social, ethical and legal issues when developing interactive media systems
- Explore how interactive media platforms support the creation of digital identities
- Investigate how digital marketing techniques influence consumer behaviour
- Examine how human behaviour may be influenced by interactive media

**Curriculum Points Covered:**

- "Investigate social, ethical and legal issues when developing and implementing interactive media systems" - "privacy issues and the use of intellectual property, including Indigenous Cultural and Intellectual Property (ICIP)"
- "Explore how interactive media platforms support the creation of digital identities" - "personal e-profiles, identifier versus identity, profiling and auto-profiling, privacy settings"
- "Investigate how digital marketing techniques influence consumer behaviour" - "guided choice (nudging), default settings including cookies, autofill, pop-ups promoting online shopping"
- "Examine how human behaviour may be influenced by interactive media, including opportunities for people with disability to explore and participate in their environment"

**Teaching Focus:**

- Digital identity and e-profiles (identifier vs identity)
- Privacy settings and data collection (profiling, auto-profiling)
- Dark patterns and ethical design (nudging, addictive features)
- Indigenous Cultural and Intellectual Property (ICIP)
- Platform responsibility and content moderation overview
- **ACTIVITY:** Analyse social media apps for ethical issues (cookies, autofill, pop-ups)

### Summative Assessment

**Learning Intentions - Students will:**

- Select an appropriate project management approach to develop an interactive media-based solution
- Apply features of user interaction and UX within web-based systems

**Teaching Focus:**

- Guided work time on Assessment 1
- Teacher feedback and support
- Project management check-ins

**Assessment Task:** Create a simple interactive media piece (website, app mockup, or interactive presentation) demonstrating:

- UX/UI principles
- Accessibility consideration
- Ethical design awareness
- Use of appropriate file formats

**Assessed Curriculum Points:**

- _Interactive Media:_ "Apply design thinking to develop a front-end, web-based interactive media system incorporating UX and UI principles"
- _Interactive Media:_ "Create interactive media systems"
- _Interactive Media:_ "Apply features of user interaction and UX within web-based systems"
